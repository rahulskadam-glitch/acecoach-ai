# Red-team checklist

## Scientific
- Does the rule confuse correlation with cause?
- Is a coaching cue represented as a measurable fact?
- Is monocular video sufficient for the metric?
- Are thresholds personalized and context-specific?

## Coaching
- Is the item a root cause, contributor or symptom?
- Could this be an acceptable technique variation?
- Does the intervention address the earliest actionable cause?
- Is only one primary correction shown?

## UX
- Can a 13-year-old understand the player message?
- Can a coach inspect evidence and measurement status?
- Does the overlay obscure the player or ball?
- Is uncertainty understandable without reading a technical manual?

## Safety and privacy
- Does language imply injury diagnosis?
- Is a minor’s video private by default?
- Can the user delete video and derived data?
- Are bystanders and location metadata protected?

## Engineering
- Is the analysis reproducible from hashes and versions?
- Are unavailable metrics excluded from score?
- Can a player correction invalidate only affected layers?
- Are model, rules, scoring, prompt and overlay versions independent?
