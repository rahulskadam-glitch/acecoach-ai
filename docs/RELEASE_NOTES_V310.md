# AceCoach AI v3.1.0 — Visual Benchmark Coach

## Product objective

Make the report immediately understandable to an athlete while preserving transparent scientific detail for coaches and advanced users.

## New athlete experience

1. **Simple movement map** — footwork, preparation, loading, body position, swing path, contact, and recovery shown in one horizontal story.
2. **Key-frame filmstrip** — report moments are converted into clickable image cards that jump to the annotated video.
3. **Reference comparison studio** — the athlete’s clip is shown beside a curated governing-body coaching reference.
4. **Checkpoint comparison** — preparation, loading, contact, and recovery can be reviewed one at a time.
5. **Technical depth on demand** — frame counts, evidence, confidence, and engine provenance are collapsed by default.
6. **Stronger improvement feedback** — athletes rate visual clarity, reference usefulness, and whether the first priority felt correct.

## Reference policy

- Tennis references use public USTA Coaching videos and the USTA high-performance technique library.
- Badminton, cricket, squash, and table tennis link to official governing-body coaching or education resources when an embeddable movement clip is unavailable.
- References are visual best-practice aids, not statistical age-group benchmarks.
- AceCoach does not claim that one elite or coach-demonstrated movement is the only correct technique.
- Licensed, phase-synchronized reference datasets remain a future requirement.

## Age-access change

The temporary under-18 product block has been removed. Required service-processing consent remains mandatory for every athlete account. The product displays a non-blocking youth-account notice so operators understand that public deployment still requires market-appropriate guardian and youth-data processes.

## Recursive improvement loop

The report feedback model now records:

- movement accuracy,
- coaching clarity,
- visual clarity,
- reference helpfulness,
- first-priority fit,
- drill relevance,
- overall usefulness,
- and the user’s explanation of the problem.

A service-role-only learning view supports governed review by engine version, sport, and movement without exposing raw video or profile names.
