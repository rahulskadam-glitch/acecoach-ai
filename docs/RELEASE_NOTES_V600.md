# AceCoach AI v6.0.0 — Simple Athlete Journey

## New canonical flow

`Sport → Sign in → Upload → Analyze → Report → Coach`

## Delivered

- Sport-only landing page for Tennis, Badminton, Squash, Cricket, and Table Tennis
- Light, spacious, professional design across the six primary steps
- Configuration-gated Google, Apple, Microsoft/Azure, Facebook, and email authentication
- Combined video upload and essential athlete intake
- Mandatory sport-specific movement selection
- Visible upload-complete and delete controls
- Queued analysis action and dedicated status page
- Explicit movement conflict resolution
- Four-section player report with one primary correction
- Direct transition from report to a persistent, report-grounded coaching conversation
- Returning-user `/home`
- Additive migration 022 and v5 compatibility routes

## Honest limitations

The release does not add photorealistic athlete reconstruction, calibrated 3D biomechanics, force measurement, automatic ball/racket tracking, or a distributed production job queue. Social providers require external Supabase/provider configuration before their buttons should be enabled.
