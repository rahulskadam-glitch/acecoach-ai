# Multi-Sport Functional Model

## Personas

- Athlete: maintains multiple sport profiles, uploads footage, receives analysis and tracks progress.
- Coach: manages assigned athletes across one or more sports and reviews evidence-backed reports.
- Academy: manages coaches, squads, sport programmes and aggregate development insights.
- Administrator: controls sport enablement, configuration, model policy and quality operations.

## Athlete journey

1. Create account.
2. Select primary sport and optionally add more sports.
3. Enter age, level, ranking/rating and goals for each sport.
4. Select sport and technique when uploading a video.
5. Receive capture-quality feedback before analysis.
6. Track processing status.
7. Review sport-specific metrics, strengths, priorities and drills.
8. Compare progress within the same sport/action and across training periods.

## Functional separation

Cross-sport comparisons are allowed only for general athletic dimensions such as balance, mobility and training consistency. Technique scores are never compared directly across unrelated sports because their metric definitions and scales differ.
